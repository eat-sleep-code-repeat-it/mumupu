# PNG-to-JPS request

Create a `/png-to-jps` page with a button to choose a PNG image, a preview of
the selected image, and a **Parse PNG** button. When clicked, use a function to
recognize the musical notes and generate a JPS script. Show the parsed JPS
below the button on the same page and save it in the `png-scripts` folder using
the same base filename as the input PNG.

The generated JPS should follow the project's existing notation and rendering
conventions.
